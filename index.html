2. Information We Collect

3. Focus Lock â€” Usage Access & Overlay Permissions

Echo's Focus Lock feature optionally uses Android's Usage Access (PACKAGE_USAGE_STATS) and Display Over Other Apps (SYSTEM_ALERT_WINDOW) to help you beat distractions by detecting when an app you chose to block is opened during a scheduled Focus session.

  • What is accessed: The foreground app's package name only (e.g. com.example.socialapp) during active focus sessions
  • What is NOT accessed: Keystrokes, passwords, screen content, personal messages, or any personal data
  • Data storage: This data is never stored, never transmitted, never shared â€” it is processed locally in real-time on-device only
  • When it runs: Only during active Focus sessions that you explicitly schedule and start
  • How to disable: System Settings -> Apps -> Special app access -> Usage access -> Echo: Life Tracker -> Turn OFF
Usage Access and Overlay permissions are used solely and exclusively for the Focus Lock self-control feature. No data is collected or transmitted through these permissions.
